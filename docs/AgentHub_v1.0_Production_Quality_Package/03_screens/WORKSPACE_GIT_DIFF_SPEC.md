# Workspace Git / Diff v1.0

## Changes view
Tree 永久存在；selected file diff 永久存在。History/Branches 放 overflow menu/drill-in。

## Tree
repo-relative；folder count；M/A/D/R/U glyph；+/- stats；keyboard tree nav；folders remember expand state。

## Diff
fill available height；language-aware；sticky file header；prev/next file；unified/split responsive；wrap toggle；whitespace menu；collapse unchanged；large diff warning。

## Commit dock
底部 compact dock；无 selection 时折叠；有 selection 后显示 count + message + commit。不要永久 3-row textarea 挤 Inspector。
