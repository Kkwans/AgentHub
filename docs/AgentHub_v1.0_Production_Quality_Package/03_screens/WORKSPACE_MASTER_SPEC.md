# Workspace v1.0 Master Spec

## Mission
整个产品最重要页面。它不是 3 个后台 panel，而是一个持续 coding workbench。

## Geometry
Top 50px；Session default 256 (216–336)；Conversation min 520；Inspector default 440 (360–760)。

## Rules
- Conversation 永远是中心视觉焦点。
- Inspector 是 review context，不抢输入焦点。
- Composer 贴近 conversation 底部，最大 readable width 820–920。
- Terminal 是 bottom dock。
- 所有 panel size 持久化。
- 空 panel 自动 collapse，不保留无效空白。

## Responsive
<1180 left collapsed；<900 inspector drawer；<680 one-view tabs。
