# Workspace Composer v1.0

Textarea 是绝对主角。默认 72–120px，内容自动 grow 到 240px。

Bottom controls：Context / Session Config / Permission / Send。最多 4 个显式 control group。

Session Config 合并 model/mode/reasoning。Terminal 移到 Workspace toolbar/dock。

Slash command menu 不覆盖整个 composer；max 360px high；keyboard accessible。

Context popover 展示 Project/cwd/branch/PromptOS/Tools/Skill，但 raw JSON variable editor 进入 Advanced。
