# Workspace Session Rail Spec

Top: workspace/project name + count；search + new。

Groups：Active / Today / Yesterday / History。Active 独立，不受日期排序。

Row 54–58px：status dot / title / branch · project(optional) · relative time。Closed 只灰点；历史 >10 折叠。

Keyboard：↑↓ selection，Enter open，Cmd/Ctrl+N new session，Esc focus conversation。
