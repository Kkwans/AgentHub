# Codex 开工前 Grill Checklist

Codex 在正式修改前必须回答：
1. 当前部署/开发如何启动？
2. 当前 v0.9 screenshot baseline 在哪里？如果没有如何建立？
3. 哪些 CSS selectors 属于 vendor bridge？
4. Settings route section 当前为什么未使用？
5. Git diff API 能否支持 file-scoped language-aware diff？
6. Session/message 数据量真实上限？
7. 哪些旧 visual tests 仍依赖 v0.7 文案？
8. 1.0 version source of truth 放在哪里？

无法从代码确认的事项要明确标注并向人类确认，不允许暗猜。
