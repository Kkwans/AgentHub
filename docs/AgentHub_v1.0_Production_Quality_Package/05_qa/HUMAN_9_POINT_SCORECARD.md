# Human 9/10 Scorecard

每项 0–10；任何 P0 项 <9 不发布。

| 项目 | 权重 |
|---|---:|
| Layout/alignment | 15% |
| Information hierarchy | 15% |
| Typography | 10% |
| Density/space usage | 15% |
| Interaction clarity | 15% |
| Workspace review flow | 15% |
| Visual consistency | 10% |
| Edge states | 5% |

## 评分解释
- 5：能用，但明显工程味/后台味。
- 7：不错，仍能发现较多不统一细节。
- 8：专业产品，但仍有少数明显 polish gap。
- 9：商业级，可以公开作为产品封面。
- 10：几乎挑不出可感知缺陷。

目标不是平均 9，而是 **Workspace、Home、Projects、Prompt、Settings 各自 ≥9**。
