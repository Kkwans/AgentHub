# E2E Matrix

## User journeys
1. first run → admin → project → agent → session → first run
2. approval → accept/reject → result
3. change tree → file diff → review → commit
4. failed run → diagnostics → continue session
5. prompt create → version → label → binding → render
6. remote node disconnected/reconnected
7. settings account/security
8. terminal open/resize/close

测试命名统一 `v1-*` 或无版本中性名，不再 `v07-*`。
