# AgentHub Design System v1

## Design language: Calm Precision

关键词：**清晰、紧凑、克制、专业、可扫描、工程感**。

不用：大渐变 Hero、玻璃拟态泛滥、过多阴影、霓虹边框、超大圆角、卡片矩阵模板感。

## 组成

1. Foundation tokens
2. Semantic tokens
3. Layout tokens
4. Component tokens
5. Workbench tokens

所有 Feature CSS 必须引用这些 token，不再复制具体 `14px/16px/18px` 魔法数。

## Component families

- Button/IconButton
- Input/Search/Select
- Segmented/Tabs
- StatusDot/StatusLabel
- EntityRow
- MetricInline
- Toolbar
- PanelHeader
- PageHeader
- Empty/Error/Loading
- Popover/Drawer/Dialog
- Tree/TreeRow
- DiffHeader
- ComposerSurface
