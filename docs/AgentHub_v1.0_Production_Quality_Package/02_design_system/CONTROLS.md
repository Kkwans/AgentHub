# Controls Contract

## Buttons
- Primary：每个 surface 一般最多 1 个。
- Secondary：default/ghost。
- Destructive：red，仅危险操作。

## IconButton
32px desktop toolbar；tooltip 必须；移动 44px hit area。

## Segmented/Tabs
同层只允许一套 tab；嵌套 tab 必须改成 local nav/drill-in/menu。

## Search
列表页 Search 占 240–360px，不默认撑满 50vw。

## Select
常规 filter 128–160px；高阶 filter 进入 popover。
