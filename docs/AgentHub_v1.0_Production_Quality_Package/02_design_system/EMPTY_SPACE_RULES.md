# Empty Space Rules

空白分三种：
1. **结构空白**：24–32px section rhythm，允许。
2. **阅读空白**：正文 max-width 留右空，允许。
3. **无效空白**：业务区域内因为 fixed min-height/Card/absolute layout 产生，禁止。

## Review questions
- 这个 100px 空白是否帮助区分层级？
- 如果删掉 40%，可读性是否变差？
- 是否只是因为卡片 min-height？
- 是否能用 dense row 替代大 card？

Home/Workspace/Settings 必须在 screenshot review 中单独标注无效空白。
