# Accessibility

- WCAG 2.2 AA 目标。
- focus visible 统一 2px violet ring。
- 键盘可完成 Sidebar、Command Palette、Session Rail、Inspector tabs、Git tree、Composer、Dialog。
- Tree 使用正确 role/treeitem/aria-expanded。
- icon-only 必须 aria-label + tooltip。
- drag separator 支持 keyboard resize 或可替代快捷操作。
- reduced motion 不播放 panel/reveal animation。
