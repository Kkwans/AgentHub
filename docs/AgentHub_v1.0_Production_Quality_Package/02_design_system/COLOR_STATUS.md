# Color / Status

品牌 Accent：Aurora Violet，仅用于 active、primary CTA、focus、selected indicator。

状态：
- success green
- warning amber
- danger red
- info blue
- neutral gray

## Status presentation

高频列表优先 `dot + text`，不是 pill。
Pill 只用于需要明确封装的状态标签。
同一行最多 2 个状态色元素。

Workspace 禁止把 accent 改成黑色；neutral workbench 可以有 `--wb-ink`，但 selection/focus 仍保留品牌 violet。
