# Density & Space Policy

## 禁止“空白=高级”

工作软件的高级感来自秩序，不来自浪费空间。

### 硬规则
- 首屏装饰性空白最大 160–180px。
- data-rich surface 内连续空白高度 >120px 必须有业务原因。
- 常规 list row 52–72px。
- project/agent card 不得为了对齐强制 180–240px 高度，除非内容真的需要。
- 路径/辅助字段不为“填满卡片”而出现。

## 密度档

### Comfortable（默认）
36px controls / 60–68 rows / 14px body。

### Compact
32px controls / 48–56 rows / 13px body。

用户可选择，但视觉 hierarchy 不改变。
