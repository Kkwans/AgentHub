# v1.0 Information Architecture

## Global Navigation

- Home
- Projects
- Agents
- Prompts
- Settings

Infrastructure / Remote Nodes 作为 Agent 二级入口，不再和主业务等权。

## Project Context

- Overview
- Work
- Sessions

Prompt Binding 通过 Prompts 过滤器进入；Project Settings 作为 Overview 的属性面板/动作，而不是重复全局 Settings。

## Workspace

- Session Rail
- Conversation
- Inspector: Changes / Files / Activity / Run
- Terminal: bottom dock（按需）

## Settings

- Appearance
- Account
- Security
- Integrations
- System
- Advanced

## Prompt Library

- Library list
- Asset editor: Content / Variables / Playground / Bindings
- Version history drawer
