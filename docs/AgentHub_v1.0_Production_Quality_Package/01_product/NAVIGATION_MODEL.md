# Navigation Model

## Global sidebar
220px，5 个 primary nav + 1 个 Infrastructure group + bottom profile。

## Command Palette
Ctrl/⌘K 同时搜索：Project、Session、Agent、Prompt、Command；结果按类型分组，不再只是 nav item filter。

## Breadcrumb
仅 detail/workspace 使用，Home/List 不用 breadcrumb。

## Local Navigation
Settings/Project Context 使用 local nav，但不得与 global sidebar 形成 3 层永久导航。

## Back behavior
Drawer/Inspector drill-in 优先返回上一 inspector view，不直接退出 Workspace。
