# Keyboard Shortcuts v1

| Shortcut | Action |
|---|---|
| Cmd/Ctrl+K | Global command palette |
| Cmd/Ctrl+B | Global sidebar toggle（非 Workspace 时） |
| Cmd/Ctrl+Shift+B | Workspace Session Rail toggle |
| Cmd/Ctrl+Shift+I | Inspector toggle |
| Cmd/Ctrl+J | Terminal dock |
| Cmd/Ctrl+Enter | Send / confirm contextually |
| Esc | close topmost overlay / return focus |
| ↑↓ | list/tree navigation when focused |

快捷键必须在 tooltip/command palette 可发现；不与浏览器常用快捷键冲突。
