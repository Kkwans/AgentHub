# Global Search / Command Palette

## v1.0 目标

当前 AppShell command palette 更像“导航搜索”。1.0 应升级为真正工作入口。

### 分组
- Recent
- Projects
- Sessions
- Agents
- Prompts
- Commands

### 支持
- fuzzy search
- keyboard navigation
- recent ranking
- exact command shortcuts
- “New Work in …” quick action

### UI
620–680px；每行 44–52px；左 type icon，中 title/subtitle，右 shortcut/meta。
