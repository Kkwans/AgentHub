# v0.4 UI 系统与首屏性能

最后更新：2026-08-10

## 目标

- 修复密码输入框原生 reveal 与自定义按钮重复的问题。
- 用有明确开源许可的成熟图标替换字母或手绘 SVG 品牌标志。
- 重构概览的信息层级、留白、响应式网格和空状态，移除所有单边强调条。
- 保持现有 Radix Themes、Phosphor Icons 与共享 UI 组件，不再创建平行组件体系。
- 拆分非首屏路由及其大块样式，减少初始 JavaScript。

## 设计决策

### 品牌

- 使用 Phosphor Core/React 的 `ShareNetwork`，以“一个控制面连接多个 Agent 节点”表达
  AgentHub；不把供应商、模型或单个 Agent 绑定到品牌标志。
- favicon 采用 Phosphor 官方 SVG path，代码注释保留来源和 MIT License；应用 UI 直接使用
  `@phosphor-icons/react`，不复制第二份手绘图形。
- 标志使用中性石墨色，运行、告警和主操作色留给真实状态与动作。

### 视觉层级

- 面板使用完整、对称的 1px 边框和统一圆角；优先级由标题、数量、状态 Badge 与顺序表达。
- 禁止用左侧 3px/4px `border-left`、内嵌色条或不对称圆角表达“需要处理”。
- 空状态必须包含下一步入口，不使用大块灰色占位区填满栅格。
- 移动端卡片之间保留 12px 间距；桌面概览网格为 16px。

### 表单

- 密码控件统一复用 `PasswordField`，只保留输入框右侧一个可见性按钮。
- `::-ms-reveal` 与 `::-ms-clear` 在组件作用域内隐藏，避免 Edge 浏览器叠加原生按钮。
- 聚焦态使用单层 2px 橙色 outline，不叠加浏览器蓝色与主题 ring。

## 性能结果

生产构建对比：

| 指标              |    拆分前 |    拆分后 |   变化 |
| ----------------- | --------: | --------: | -----: |
| 首屏 JavaScript   | 645.07 kB | 337.15 kB | -47.7% |
| 首屏 gzip         | 192.71 kB | 106.44 kB | -44.8% |
| 500 kB chunk 警告 |        有 |        无 | 已消除 |

`OverviewPage`、`ControlPages`、`PromptOsPage`、`WorkspacePage` 使用路由级 lazy loading；
PromptOS 与 Workspace 的专用 CSS 跟随对应路由 chunk 加载。

## 验收合同

- 静态门禁：Prettier、ESLint、TypeScript、Vitest、Vite production build。
- TX5Pro：Chrome 150，1440/1024/768/390，无根页面横向溢出。
- 密码控件：每个密码输入框只有一个可见性按钮，原生 reveal 不占据布局。
- 概览：四个完整面板，无灰色空洞、无单边强调条；移动端 gap 至少 12px。
- 运行时：0 request failure、console/page/HTTP error 和外部请求。

## 部署与回滚

- 正式镜像：`agenthub:0.3.0-nas.6`。
- Compose Project：`/volume2/DockerProject/agenthub/docker-compose.yml`。
- 切换前备份：
  `/volume2/DockerProject/agenthub/{docker-compose.yml,.env}.pre-nas6-20260810T143744Z`。
- 回滚时恢复上述两份配置，运行同一 Compose Project 的 `up -d --no-build agenthub`，然后
  核对 `/api/v1/health`、Project 数据和既有 Agent 容器状态；无需删除 `nas.6` 镜像。

## 未扩大范围

- 本阶段不修改既有 Claude Code、Hermes 或 OpenClaw Compose、镜像和数据卷。
- 不把 fixture 视觉验收描述为真实管理员业务流验收。
- 不新增主题系统、动画框架、第二套 Icon 包或浏览器文件写入能力。
