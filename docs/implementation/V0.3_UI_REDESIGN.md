# AgentHub v0.3 UI/UX 重构轻量 SDD

状态：已接受  
日期：2026-08-10

## 目标

把现有功能完整但视觉粗糙的 Web Shell 重构为可长期使用的专业 Agent 工程控制平面。保留现有中文信息架构、路由、REST/WebSocket 契约与真实数据闭环，替换重复实现的基础控件、单体 CSS 和弱交互模式。

## 当前事实

- AgentHub 当前没有部署为 NAS 常驻进程、Docker 容器或 systemd service；NAS 没有监听 `3210`。
- `3210` 是 Central Server production 默认端口，默认仅绑定 `127.0.0.1`。
- TX5Pro 截图来自验收期间的临时 host-native Server，验收后已回收。
- Web 已使用 React 19、Vite 8、Tailwind 4、TanStack Query、Monaco 与 react-resizable-panels。
- `packages/ui` 当前只导出包名；没有承载真实组件系统。
- Web 没有安装 Radix Themes 或 shadcn 组件，主要使用原生表单、手写按钮/卡片/Badge 与 Lucide。
- `apps/web/src/styles.css` 约 74 KB，`ControlPages.tsx` 约 68 KB；样式和页面职责过度集中。

## 设计审计

| 问题                       | 证据                                                    | 重构方向                                                                     |
| -------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 组件库名义存在、实际未使用 | `packages/ui` 为空壳，页面直接渲染原生控件              | 采用官方 Radix Themes 组件并建立真实 UI package                              |
| 视觉过度装箱               | 设置页和概览由大量同质白卡片组成                        | 用层级、分组、DataList、Table、Callout 与留白代替卡片墙                      |
| 设计语言通用且陈旧         | 深蓝侧栏、亮蓝按钮、9px 大写 eyebrow、Inter 默认栈      | 改为石墨中性色、单一橙色操作强调、中文 UI 字体栈和克制标签                   |
| 交互状态重复实现           | Button、Badge、Dialog、Tabs、表单、Tooltip 均为手写 CSS | 使用 Radix Button、Badge、Dialog、Tabs、Select、TextField、Tooltip、Skeleton |
| 页面和 CSS 单体过大        | 单文件包含所有领域页面和 3000 余行样式                  | 按 Shell、Control、Task、Workspace、PromptOS 拆分模块                        |
| 存在无行为控件             | 全局搜索、会话筛选、Terminal 按钮等没有完成闭环         | 实现真实命令导航，未支持动作隐藏或明确 disabled + 原因                       |
| 移动端阅读成本高           | 设置页变成超长单列卡片流                                | 使用分组导航、渐进披露和移动 drawer，保持 44px hit target                    |
| 可访问性不稳定             | 原生弹层、自定义 Tabs 和图标按钮需要逐项维护焦点        | 交给 Radix 管理 focus trap、键盘、ARIA，并补充语义测试                       |

## 设计解读

这是面向专业软件开发者的高密度 Agent 控制平面，不是营销页。视觉语言采用克制、精确、偏 Linear/Arc 工具感的操作界面。

- `DESIGN_VARIANCE: 5`：允许不对称主次布局，但不牺牲扫描效率。
- `MOTION_INTENSITY: 3`：只做 hover、press、drawer、tab 与状态切换反馈，全部尊重 reduced motion。
- `VISUAL_DENSITY: 7`：支持长路径、状态、日志与多栏工作区，数据使用 tabular/mono 字体。

## 组件系统

只采用一套产品组件系统：

- `@radix-ui/themes@3.3.0`：Button、IconButton、Badge、Callout、Dialog、DropdownMenu、Tabs、Select、TextField、TextArea、Table、DataList、Skeleton、Tooltip、ScrollArea、Separator 与布局 primitives；
- `@phosphor-icons/react@2.1.10`：统一图标家族，不手写 SVG；
- Tailwind 4：只承担布局、响应式和少量产品特定排版，不重新实现 Radix 基础控件；
- TanStack Query、Monaco、react-resizable-panels：继续复用现有数据、编辑器和多栏能力。

不同时混用 Fluent、Carbon、Material、Primer 或另一套组件系统。shadcn 仅作为 Radix 模式参考，不复制默认样式，也不再维护第二套 Button/Card。

## 视觉系统

### 色彩

- `Canvas #F6F7F8`：应用背景；
- `Surface #FFFFFF`：可交互工作面；
- `Graphite #202124`：主要文字；
- `Slate #667085`：辅助信息；
- `Line #E2E4E8`：边界；
- `Signal Orange`：唯一非语义操作强调，使用 Radix Orange scale。

成功、警告、失败、在线等颜色只表达真实状态，不作为装饰。整站保持同一浅色主题，v0.3 不增加无产品需求的主题切换。

### 字体与形状

- UI：`Segoe UI Variable`、`PingFang SC`、`Microsoft YaHei UI` 与系统 sans fallback；
- 路径、ID、branch、command、数字：`Cascadia Code`、`SFMono-Regular`、Consolas 与 monospace fallback；
- 容器 radius 10px，输入 8px，按钮 8px；pill 只用于状态和短筛选；
- 正文最小 12px，移动端输入最小 16px，关键点击区域移动端最小 44px。

### 识别性元素

“运行脊柱”作为 AgentHub 的签名元素：Dashboard、Task 与 Session 用一条连续的状态轨道表达 queued、running、approval、review 与 done，取代无意义 KPI 卡片和装饰圆点。颜色只来自真实状态。

Workspace：

```text
┌──────────┬──────────────────────────────┬──────────────────────┐
```

小于 1024px 时转为 tabs；小于 768px 时一级导航和 Inspector 使用 drawer，主任务保持单列。390px 不允许根页面横向滚动。

## 页面重构

1. Shell：真实 command palette、轻量导航、连接状态、跳到主内容、移动 drawer。
2. 概览：按“现在处理”“正在运行”“最近结果”“执行基础”组织，不使用 KPI 卡片墙。
3. Project/Agent/Session：Table/DataList + side panel，长路径和 capability 渐进披露。
4. Task/Worktree：看板与运行脊柱并存，Review 用 Radix Dialog/AlertDialog，危险操作明确分级。
5. Workspace：保持三栏，统一 panel header、message、tool、Approval 与 Composer 层级。
6. PromptOS：Master-detail、Tabs、Diff、Binding 和 Playground 使用标准控件，减少重复边框。
7. 设置：按“服务与访问”“Remote Node”“执行能力”分组，避免超长卡片流。

## 可访问性与质量门禁

- 所有流程可用键盘；focus-visible 清晰，弹层打开/关闭正确移动并返回焦点；
- 图标按钮有 accessible name，纯装饰图标隐藏；
- loading 使用 Skeleton，空状态给出下一步，错误说明原因和恢复动作；
- 表单 label、helper、error 完整，不能用 placeholder 代替 label；
- reduced motion 下取消非必要过渡；
- 1440、1024、768、390 测试导航、表格、drawer、Dialog、Workspace 和溢出；
- 使用最新 Web Interface Guidelines 做静态审查；
- TX5Pro Chrome 做真实视觉、键盘、交互、console、page error、failed request 与 HTTP 失败检查。

## 部署与自身 Project 注册

UI 验收完成后采用 host-native Node 服务：

- 监听 `127.0.0.1:3210`，不创建 AgentHub Docker；
- 使用独立持久目录保存 PGlite 和 worktree；
- systemd unit 以 `Kkwans` 用户运行，配置 `Restart=on-failure` 与最小写入路径；
- 上线前保存当前 commit、构建产物校验和、service/env 备份和回滚命令；
- 健康检查通过后，通过真实 API 注册 `LOCAL_HOST` target，并将 `/volume2/Project/AgentHub` 注册为 Project；
- 不修改或启停 Claude Code、Hermes、OpenClaw 的 Docker/Compose、镜像或 volume。

## 成功标准

- Radix 组件覆盖基础交互，`packages/ui` 不再为空壳；
- Lucide 与旧 `.button`/`.status-badge` 等重复 primitive 被移除；
- 所有现有功能测试、类型检查和 build 通过；
- 新增组件、可访问性与四视口浏览器回归；
- TX5Pro 实机视觉验收完成并归档截图；
- NAS 常驻服务健康、端口明确、重启可恢复，AgentHub 自身 Project 可见且 preflight 通过。

## 回滚

- 每个页面切片独立 commit，可逐项回退；
- 新依赖由 lockfile 固定，回退 commit 可恢复旧 Web build；
- 部署保留上一已验证 commit/build 和 service/env 备份；
- 数据库 migration 不属于本重构，Project 注册只新增记录；
- 回滚不删除数据库、worktree、Remote Node identity 或任何 Agent Docker 数据。
