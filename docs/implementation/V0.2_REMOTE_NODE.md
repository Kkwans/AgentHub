# AgentHub v0.2 Remote Node 轻量 SDD

## 目标

让中央 AgentHub 通过安全的 outbound WebSocket 管理远程主机上的 Agent、Project 与 Run，
远程主机无需开放入站管理端口，provider credential 始终留在 Node。

## 范围

### 本切片包含

- `apps/node` daemon、设备 identity、本地配置与 reconnect；
- one-time registration token、Ed25519 challenge/signature、revoke 与在线状态；
- per-target repository roots、Agent inventory/capability 和 heartbeat；
- versioned Node RPC、超时、payload 上限、断连处理和事件流；
- `REMOTE_NODE` Execution Target、远程 Project preflight/只读文件访问；
- 远程 Agent preflight、Session/Run/Approval/cancel/close 闭环；
- 中文 Node 注册、状态、诊断与连接指引；
- protocol、repository、gateway、daemon integration 与浏览器测试。

### 本切片不包含

- SSH target、通用远程 shell、任意 command API；
- 复制 provider credential、HOME、SSH key 或 auth 文件；
- 远程 Terminal、Docker 管理、文件写入 API；
- 透明 Session resume、离线命令重放、多中央服务器或 Node 高可用；
- Remote Worktree merge。v0.2 先跑通远程普通 Task/Session；Worktree RPC 复用点保留但不伪称已完成。

## 注册与身份

1. 已认证用户创建 registration token，提供 Node 名称与一个或多个绝对 repository root；
2. 中央保存 token hash、expiry、roots 与一次性状态，明文只返回一次；
3. Node 生成 Ed25519 key pair并以 `0600` 保存 private key；
4. Node 连接 `/node/ws`，对中央 challenge 签名并提交 token、public key 与本地 inventory；
5. 中央原子消费 token，创建 `remote_nodes` 与 `REMOTE_NODE` target，返回 node/target ID；
6. 后续连接只使用 node ID + challenge signature；revoke 后所有新连接拒绝，现有连接关闭。

签名 payload 固定为 UTF-8：

```text
agenthub-node-v1\n<mode>\n<node-or-register>\n<challenge>
```

## Node WebSocket 协议

端点：`/node/ws`，协议版本：`agenthub-node-v1`。单条消息不超过 1 MiB。

```text
Server -> Node  challenge / registered / authenticated / command / error
Node -> Server  register / authenticate / heartbeat / result / event
```

RPC allow-list：

```text
project.preflight
fs.list
fs.read
agent.preflight
agent.capabilities
session.create
session.run
session.approval
session.cancel
session.close
```

每个 `command` 有 UUID request ID 与 30 秒默认 timeout；Agent Run 创建可快速返回，streaming
事件使用 `event` 消息。断线时所有未决 RPC 拒绝为 `REMOTE_NODE_DISCONNECTED`，不自动重试。

## 数据与 API

新增表：

- `remote_node_registration_tokens`：name、token_hash、allowed_roots、expires/used/revoked；
- `remote_nodes`：target_id、public_key、fingerprint、protocol_version、daemon_version、roots、
  inventory、status、last_seen、revoked_at。

REST：

```text
GET  /api/v1/remote-nodes
POST /api/v1/remote-nodes/registration-tokens
POST /api/v1/remote-nodes/:id/revoke
GET  /api/v1/remote-nodes/:id/diagnostics
```

registration token 响应中的 `token` 只出现一次；list/diagnostics 不返回 token hash 或 public key
原文，只返回 fingerprint。

## 路径与执行边界

- 注册 roots 和 Node 本地 roots 都必须是 absolute realpath directory；至少一个匹配才能上线；
- 所有 Project/cwd/文件请求在 Node 上重新做 lexical + realpath containment 和 symlink escape
  防护；中央数据库路径不是授权依据；
- Agent 只能来自 Node 上报的 inventory，Node 以固定 profile/argv/`shell:false` 启动；
- Node 不接受中央提供的 environment secret、任意 executable 或 shell command；
- 文件接口保持只读，2 MiB/二进制/5000 entries 限制与本机一致。

## 状态与恢复

- Node：`PENDING | ONLINE | OFFLINE | REVOKED`；Target：`READY | OFFLINE | REVOKED`；
- heartbeat 每 15 秒，中央 45 秒无心跳视为 `OFFLINE`；
- daemon 指数退避 reconnect（1–30 秒 + jitter）；
- Server restart 后 Node 自动重连并重新签名；registration token 不会重用；
- 断线中的 remote Run 进入 `DISCONNECTED`。v0.2 不自动重放 prompt、approval 或 cancel。

## 验收

- token expiry/reuse/revoke、伪造签名、错误 public key、重复连接均被拒绝；
- `ws://` 非 loopback、root 不匹配、traversal、symlink escape、超大消息、未知 RPC 均被阻止；
- Node inventory/heartbeat 驱动 Target 在线状态，不上报 secret；
- 临时远程 fixture 完成注册、Project preflight、只读文件、Codex preflight、Session stream、
  Approval/cancel/close；断线使未决请求和活动 Run 明确终止；
- 中文 UI 覆盖创建注册码、一次性警告、连接命令、在线/离线/revoked 与诊断状态；
- lint、typecheck、unit、build、Playwright 和受环境 gate 控制的 live test 通过。

## 回滚

- revoke 或停止 Node daemon，不删除远程 repository、Agent auth、Session 或设备历史；
- migration 向前追加，发布前备份 PGlite/PostgreSQL；
- 代码回退不删除 `remote_nodes`/token 表；必要时恢复升级前数据库备份；
- Node 数据目录由目标主机用户管理，AgentHub 不远程删除 private key。
