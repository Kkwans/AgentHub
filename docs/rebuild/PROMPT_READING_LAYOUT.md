## 本片设计

1. 页头标题和“新建Prompt”在手机同排；说明缩为一句用途，省去重复概念。
2. 空态显式24px顶部节奏，左右仍统一页面轴线。
3. 手机目录摘要压为一个44px操作行，搜索/筛选持续挂载，不因收起丢状态。
4. 当前资产完整长名按20/28自然换行；状态保持外显，不以省略遮掉关键身份。
5. 主版本操作在DOM和视觉读序均优先。key、kind、日期、刷新与版本标签置于低频原生details，打开弹窗不自动收起，保证关闭能回焦可见触发器。

## 不改变的安全与业务边界

不改hook、API、选中资产身份、版本/绑定mutation、UNKNOWN持久记录及结果归属。绑定操作结果仍在页面外层显示；版本UNKNOWN仍在原弹窗内显示。加载/读取错误不得被当作“尚未创建版本”。原生details不宣称具备Escape或外点关闭的完整菜单行为。
