# 长分支项目页头：全宽元信息

## 实图问题

239真实长字段768截图中，标题、操作按钮与事实摘要竞争同一横向空间，摘要实际约280px。长分支使其他单行flex字段被压成“Gi”“1个登”“0项…”片段，完整信息仅hover title不足以服务触摸/键盘。

## 最小方案

仅`!compact && !compactWorkDetail`将原全部事实移动到标题/操作行之后的独立全宽可访问分组。局部CSS允许每项整体换行，长分支完整折行，不裁切、不缩成碎片。标题和操作仍保持原位置，原手机details、警告、项目资格与工作数量逻辑不变；“最近会话分支”仍是历史上下文，不冒认当前HEAD。

## 验证计划

保原页头语义测试，新增长分支与事实独立分组、不含标题/按钮、不藏details、原导航合同。真实长字段8场景保留，在非手机宽度新增四事实全文Range、可见宽度与页头截图；不通过title或纯DOM存在替代可见性。等待精确截图确认自然高度和对齐，局部单测不代表视觉通过。
