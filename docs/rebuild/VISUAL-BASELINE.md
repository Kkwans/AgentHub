## 核心设计决策

1. 首屏只强调当前最有用的下一步，而非零值 KPI。
2. 空项目状态提供一个连续开始路径，真实失败/批准仍保留，不因没有项目而隐藏阻塞。
3. 对全局 READY Agent 使用明确限定文案，不能暗示适配当前仓库。
4. 保留浅/深主题与四个必要视口；新的首页切片需重新在实际浏览器生成截图后复核。
5. 不通过给旧 CSS 再叠全局覆盖重做视觉，先在局部组件边界清理并迁移。

## 功能失败的当前调查

- Workspace 实际截图存在“Agent 对话”区域与输入框；旧 `.conversation-title` 断言不匹配现实现。改用用户可见语义且保留功能断言。
- Git 提交截图显示真实错误卡，trace 返回 409 `GIT_COMMIT_FAILED`。隔离 fixture 初始化仅用一次性 `git -c user.name/email`，后续服务端提交缺少本地身份；需修复测试仓库初始化并验证实际 HEAD/文件，不替用户配置生产 Git 身份。
