## Agent 下一片设计顺序

1. 页头把标题与唯一“发现 Agent”主动作编成一组；手机在实际可用宽度内对齐两端，必要时自然换行，不以截断标题换空间。
2. 描述只保一句用途。统计压成轻量摘要行；基础设施导航只保一个明确低频入口，不在说明、逐行与页尾重复三次。
3. 每行第一层为身份、类型/版本与真实登记/启停状态；第二层为运行环境、Provider与能力。缺失Model不制造一整行空信息，但真实默认Model可见。
4. 加载失败、未知关联、未启用不能转成绿色可用；“登记就绪不代表本次运行预检通过”语义仍可找到，避免每行重复冗长说明。
5. 管理入口保持清楚。服务器级诊断明确不是Agent专属检查，导航用途不能被压缩误导。

- 保44触点、键盘顺序与焦点、搜索/筛选/刷新、未知语义和原导航目标。
- 不新增供应商接入、真实登录、归档或部署；不覆盖用户保存偏好。
