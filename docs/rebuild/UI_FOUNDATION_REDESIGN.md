# UI 整体视觉重构：统一壳层与阅读秩序

## 2026-11-14 12:29 UTC 方向调整

用户明确现代、美观、有设计感、自然、和谐是最高优先级，并指出左上logo歪、页面排版对齐不佳。暂停归档服务/UI及其它零散功能扩展；已有DB分片不等于归档功能完成。继续收尾已发CI，但不能用“不溢出”或测试通过代替美学验收。

## 实际证据与原因

- 已人工查看历史6f项目1440原图，明确是旧版参考，不冒称当前像素：logo内图形偏左上、标题/标签/工具栏/列表多轴，主次层级弱。
- 源码确认`agenthub-logo`没有样式定义，64% ShareNetwork图标依赖行内基线，没有居中容器。两套品牌字号和padding不同。
- 全局导航228px、旧token220px、Workspace默认256px并存；公共标题32px页边与正文动态clamp不一致。项目详情没有统一页边，概览自行缩18px、工作toolbar自行缩12px；Agent详情又最大1000px居中。
- 这些是布局系统冲突，不应靠逐页面追加临时边距修补。

## 第一片设计合同

| 维度   | 统一规则                                                             |
| ------ | -------------------------------------------------------------------- |
| 品牌   | 32px槽位、约20px实际图形、16/24字标，视觉中心一致                    |
| 导航   | 默认240px；Workspace保留用户已保存的栏宽，不强制重置                 |
| 页边   | 桌面24px，手机16px；容器只拥有一次padding                            |
| Chrome | 56px基础高度；说明/动作需换行时允许自然增高，不裁切内容              |
| 文字   | 页面标题24/28，正文14/20，辅助12/18；避免随视口不断膨胀              |
| 间距   | 4/8/12/16/24/32；标题、tabs、toolbar、正文同一主轴                   |
| 表面   | 中性实色、轻分界、单工作面；删除无意义双卡片套壳与阴影               |
| 阅读   | 限制长文/表单阅读宽度，不把整个页面做窄居中卡；对话820px阅读宽度保持 |

品牌使用生成的单色中枢H **候选**，不是已获美学验收的最终标识。原透明PNG保留来源，不手写另一套替代图形；CSS mask继承主题色，依据原图透明边界补偿显示大小。需与新壳同屏在20/32px实际浏览器评估；居中只算几何正确，不能称独特或好看。

## 安全与验收

- 不改API、Provider、会话/任务状态、UNKNOWN恢复语义；不重置用户布局偏好。
- 手机现有恢复卡16px所有权保留，不引入根级二次padding。
- 独立CR检查CSS层叠、公共与页内样式边界、可见焦点、横溢和品牌对比度。
- 四宽×双主题真实隔离浏览器：项目、Agent、Workspace完整页与品牌细节，附真实DOM几何和原图。测试数据明确标记，不假称真实供应商。
- 人工逐页审查节奏、层级、留白、对齐、现代感；截图发现不和谐继续修，不因几何通过就结案。
