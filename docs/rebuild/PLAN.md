## 完成定义

不是“所有页面都有”或“测试数增加”。必须真实完成核心旅程，状态与实际行为一致，UI 经过新鲜截图验收，台账每个关闭项有证据，数据与权限边界保留，目标部署环境的限制明确。

## 审查后补充分解

- M1.2a：先修 Session 级并发准入（AH-012），真实 PGlite 证明单次 Run 持久化与发送；不同 Session 不互相阻塞。
- M1.2b：随后修 NewWork 的部分成功恢复（AH-001），不能用前端按钮锁替代后端准入。
- M1.2c：明确长指令与短标题契约（AH-013），避免用户正常长任务被 240 字上限拒绝。
