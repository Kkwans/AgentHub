# 任务规划

## 执行原则

优先核心使用路径与安全问题，视觉重构与流程修复并行设计但分切片实现。每次定时唤醒检查执行台账、Git、CI和现有工作者，继续一个清晰切片，禁止并发重复改同一模块。

| 里程碑 / 切片           | 模块                           | 依赖           | 交付与验收                                                            |
| ----------------------- | ------------------------------ | -------------- | --------------------------------------------------------------------- |
| M0.1 基线审查           | 全仓库、历史文档、运行环境     | 无             | 审查、问题台账、方案、计划、执行台账，证据分级                        |
| M0.2 真实旅程基线       | server/web/e2e-real            | 依赖安装/build | 首次进入、项目、Agent、创建工作、Workspace 真实页面；记录失败而不隐藏 |
| M1.1 保留完整任务目标   | TaskService + tests            | M0.1           | 目标+说明+验收不丢失，回归通过                                        |
| M1.2 创建恢复与单次启动 | NewWork/Task/DB                | M0.2           | 已创建任务失败后不重复；未知结果明确；并发安全                        |
| M1.3 Prompt 真正生效    | PromptOS/Task/Run              | M1.2           | 选定版本/变量/来源进入 Run，缺项拦截                                  |
| M1.4 项目与 Agent 选择  | projects/discovery/UI          | M0.2           | 嵌套仓库、禁用/离线/需认证明确可恢复                                  |
| M1.5 会话撤销           | auth/WS/PTY                    | 复现 AH-005    | 注销/改密/token 撤销停止旧连接且不影响健康主体                        |
| M2.1 视觉基线与设计样板 | design tokens/shell            | M0.2           | 首页/项目/工作台样板，浅深色与四视口验收                              |
| M2.2 核心页面迁移       | shell/projects/workspace       | M2.1 + M1      | 单一组件体系、导航、创建与审阅闭环，移除废弃层                        |
| M2.3 管理与辅助页面     | Agents/PromptOS/settings/tasks | M2.2           | 同一视觉语言、中文信息层级、完整状态与键盘流程                        |
| M3.1 生命周期拆分       | SessionService/runtime         | M1 保障测试    | 职责边界、故障恢复与重启不重放                                        |
| M3.2 性能与长期运行     | discovery/events/logs/UI       | 实测 profile   | 有界内存、请求去重、缓存失效、长内容渲染                              |
| M4.1 发布级回归         | CI/docs/deploy                 | M1–M3          | 全量检查、真实服务测试、视觉复核；真实 Agent/NAS 未测明确阻塞         |
| M4.2 最终 CR/交付       | 全仓库                         | M4.1           | 独立 CR，无未处理高风险项；记录剩余限制与升级/回滚                    |

## 完成定义

不是“所有页面都有”或“测试数增加”。必须真实完成核心旅程，状态与实际行为一致，UI 经过新鲜截图验收，台账每个关闭项有证据，数据与权限边界保留，目标部署环境的限制明确。
