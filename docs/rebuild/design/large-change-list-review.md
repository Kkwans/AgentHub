## C40 已实现候选

仅在专注模式给文件列表最大高度和纵向滚动，保留所有节点、checkbox、预览按钮和目录折叠状态，默认非专注布局不变。候选使用 `max-height: min(240px, 24dvh)`、纵向 auto 滚动、min-height:0 和 align-content:start。原三文件列表自然高度不强撑；实际效果须新截图验收，不能以 CSS 数值代替可读性。

相比新增默认折叠目录，局部滚动不需要自动隐藏当前焦点或新的展开状态。代价是嵌套滚动，需实际检查触控/键盘可达，不强制 overscroll 锁定阅读。错误、Git 状态、提交回执和提交草稿必须留在列表滚动区之外。
