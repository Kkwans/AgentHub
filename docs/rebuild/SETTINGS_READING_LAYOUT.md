# Settings 页面层级与对齐方案

## 证据边界

手机页头重复SETTINGS徽章、当前“外观”chip，下面还有六分区导航和“外观偏好”标题；首个主题控件约y455。内容在页面16px内又缩16px，和其它页左轴不一致。桌面整页居中限宽也让页头轴偏移。

## 实施方向

- 页头保“设置”和一句用途，去重复徽章/current chip，Infrastructure解释留在已有系统分区。
- 手机六分区仍3×2可见、每项44px；桌面保导航侧栏，不用隐藏尾部横滚或难发现下拉换取空间。
- 页头全宽对齐主壳，正文控制阅读宽；手机16px、桌面24px轴一致，移除双重内缩。
- 内容标题与说明紧凑；偏好名称与44px控件合理同行、说明可置下层。长安全/账户内容自然堆叠，不强压宽度。
- 只改展示与局部样式，不改偏好存储、主题行为或业务请求。

## 保留与验证

六NavLink的URL、aria-current、键盘Enter、前后退必须保持。密码/token弹窗触发器不收入会隐藏的折叠区；错误、权限未知、一次性token和退出提示保持可见。跨分区卸载既有行为不额外改变，不引入视口切换卸载或请求归属变化。

复用settings-header-visual、settings-mobile-navigation四宽与浅深真实截图/几何，加标题轴与首屏内容检查；检查最终computed几何，因为全局workspace-settings类也参与样式。重点是层级和读序，不只是无溢出；产品、单测、浏览器通过与人工审美分别报告。
