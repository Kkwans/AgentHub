本规格描述目标，不代表已实现或视觉验收。当前控制面能在隔离本地服务启动，但浏览器受 socket 权限限制；尚不能以历史截图替代本轮截图。先以真实旅程与控件行为定义设计，再在可运行的浏览器中收敛视觉。

## 1. 信息层级

1. 全局层仅保留继续工作、项目、Agent、PromptOS、设置；任务与会话可在项目和全局快速切换，避免为了开始工作连续理解多层实体。
2. 项目层固定显示项目名、执行位置、仓库/分支、可用性与一个主要操作。
3. 工作层固定显示当前任务目标、执行状态、Agent、批准/停止；文件与审阅是上下文区域，不挤占主要阅读空间。
4. 中文说明优先；Agent、Git、Terminal、模型与协议原名保留。内部状态枚举只在诊断中显示。

## 3. 布局与视觉约束

- 桌面侧栏稳定，不因页面内容重排；工作台正文有最大阅读宽度，辅助面板可收起与调整。
- 1440：主要内容与审阅同屏；1024：辅助面板缩为可切换区；768：单主区加抽屉；390：正文单列，底部关键动作不被输入法/安全区/弹窗遮挡。
- 正文字号以 14–16px 为基础，辅助信息不得靠低对比度小字隐藏；长路径使用截断+可访问全文，不破坏布局。
- 中性背景与有限强调色，状态色只表达语义；成功不是唯一依靠绿色，错误不是唯一依靠红色。
- 边框、阴影、圆角按层级统一；不要每张卡片都发光/渐变/高阴影。
- hover、focus、pressed、disabled、loading 均有一致反馈；交互区域不能只看起来像按钮却无动作。
- 动效只帮助定位和状态变化；短过渡为主，支持 prefers-reduced-motion，不做影响长时间使用的循环装饰。

## 4. 核心流程状态机

### 新建与启动

- 提交前：校验项目、Agent 可达性、指令长度和 Prompt 变量，保留完整草稿。
- 创建中：锁定同一操作，显示明确进度；不得双击创建两个任务。
- 创建成功：保存 taskId，后续任何启动失败都显示这个事实。
- 启动失败：展示实际原因，提供查看任务、选择其他兼容 Agent 或恢复启动。
- 结果未知：不自动重放可能已执行的动作；只读查询任务/Run 状态后再决定。
- 关闭/返回：未提交草稿可恢复；已受理任务继续显示于任务中心，页面消失不等于取消。

### 批准与停止

- 显示 Agent 原生选项，不创造通用“永远允许”。
- 点击后显示等待服务确认；重复点击不可产生第二次决策。
- 断网/超时不把未确认批准显示为已成功。
- 停止区分请求中、已确认停止、连接已断但结果未知；不能先清空用户的操作上下文。

### 审阅与返工

- 始终能看到原始目标、补充说明和验收标准。
- 返工必须保留原任务上下文及本次反馈，不因描述字段存在而丢失标题。
- Git提交/合并的目标、文件和分支需可见，禁止默默包含所有工作区变更。

## 5. 设计系统迁移策略

1. 列出每类原语实际使用者与行为差异，不按文件名盲目合并。
2. 选定统一 token 与组件 API，先迁移 Shell、新建工作和 Workspace 三个样板。
3. 样板通过实际截图、键盘、错误状态和流程测试后，再迁移其余页面。
4. 每迁移一类删除对应旧 CSS/组件入口及未使用导入；不另叠全局覆盖。
5. 组件行为测试与视觉证据同时保留；源码字符串测试只约束边界，不替代交互测试。

## 6. 验收矩阵

- 四视口 × 浅/深主题；键盘、屏幕阅读器语义、200%缩放、减少动态效果。
- 首次进入、已有数据、长文本/路径、空态、加载、读取失败、部分成功、断线与恢复。
- 创建后启动失败、连点、关闭/返回、切项目、Agent被禁用、Prompt缺变量、任务已被其他请求改变。
- console/pageerror、横向溢出、焦点丢失、弹窗背景滚动、主要动作被遮挡。
- 每次记录实际 commit、URL/数据准备方式、截图与测试结果；fixture、本地真实服务、真实 Agent/NAS 分开。

## 7. 独立审查补充

- 全局主侧栏 + 项目内二级导航；项目子页保持“项目”高亮，设置分区保持“设置”高亮，浏览器前进/后退恢复明确目标。
- 创建本身响应丢失时使用提交前生成的操作 ID 核对；不能因没拿到 taskId 就重新创建。
- 请求归属原项目/Agent/Prompt版本/草稿，关闭或切换后迟到结果不覆盖当前页面。
- Prompt 默认采用预览确认时的固定版本任务绑定，返工沿用；新版本需显式选择并预览。
- Run完成、待审阅、用户确认完成分别呈现；完成任务不等于提交或合并Git。
- 每个 P0/P1 关联回归、提交、真实流程证据；性能阈值待实测基线后确定。字号/间距仍是候选设计参数。
